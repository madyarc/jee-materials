Progressions: add or multiply

An arithmetic progression (AP) adds the same step every time. A geometric progression (GP) multiplies by the same factor every time. Almost everything in this chapter follows from two pictures: a staircase for the AP and a chain of shrinking hops for the GP. Move the sliders first and read the formulas afterwards. They are captions on what you see.

1 · AP: a staircase

Each bar is one term. Every bar is d taller than the one before it, so the tops lie on a straight line. Turn on the flipped copy: put the same staircase upside down on top and every column reaches the same height.

2 · GP: hops that scale

Start at 0 and hop forward by a. Each later hop is r times the previous one. Each row is one hop, so read the picture from the top down. When |r| < 1 the hops shrink and pile up against a fixed point. Remove the first hop and what's left is the whole series again, scaled by r. So S = a + rS, which gives S∞ = a/(1 − r).

3 · Add or multiply? Telling them apart

Most marks in this chapter are lost by using the right formula on the wrong kind of sequence. Plot the terms twice. An AP has equal gaps, so its points lie on a straight line on ordinary axes. A GP with positive terms has equal ratios, so its points lie on a straight line on a log axis, because log turns "× r" into "+ log r".

Two terms never settle it: 2, 6 starts both the AP 2, 6, 10 and the GP 2, 6, 18. Each new term gives one more difference and one more ratio to check. Use four terms when you have them, then predict a fifth to confirm.

Same start, same word "loses"

Two machines each cost ₹15,625. One loses 20% of its current value each year (GP, r = 0.8). The other loses a flat ₹2,500 a year (AP, d = −2,500).

Read the words: amount or percentage?

If the change is an amount with units (₹500, 2 seats), the sequence is an AP. If it is a pure number or a percentage of the current value (8%, half), it is a GP. For rates and speeds, flip to reciprocals (HP). rule of thumb, check the base

4 · AP × GP: the arithmetico-geometric series beyond NCERT

Term k is (a + (k−1)d)·rk−1. Draw it as a column: its width is rk−1 (shrinking, GP) and its height is a + (k−1)d (growing, AP), so its area is the term. Read the same cells row by row and every row is a plain GP.

The exam method: multiply by r and subtract

Shifting rS one place right lines up terms whose AP coefficients differ by exactly d, so the middle becomes a plain GP. This is the same idea as the rows of the picture. Derive the finite-n version this way each time rather than memorising it.
